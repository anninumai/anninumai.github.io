# ABOUT navigation font

`about-bold.woff2` is a Google Fonts subset of Zen Kaku Gothic New Bold (700),
containing only A, B, O, U, and T (1,064 bytes). The existing desktop navigation
requested weight 600 and resolved to this 700 face; keeping that exact face
preserves its appearance on mobile without relying on device fonts.

CSS request: https://fonts.googleapis.com/css2?family=Zen+Kaku+Gothic+New:wght@700&text=ABOUT&display=swap

Downloaded October 5, 2026 with a modern browser user agent (WOFF2 response).
The font is distributed under the SIL Open Font License in `OFL.txt`.
The CSS-only family alias `V2 About` scopes this subset to the navigation;
it does not replace the font used for body text.
